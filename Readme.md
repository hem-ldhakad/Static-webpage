Exploring React Icons
--
One of the new concepts I learned in this project was using the React Icons library to enhance the application's UI.

**Installation**
```
npm install react-icons
```

**Importing Icons**
<br/>
I imported only the required icons from the Font Awesome collection:
```
import { FaGithub, FaLinkedin, FaEnvelope } from "react-icons/fa";
```

**Using Icons in JSX**
<br/>
React Icons can be used just like any other React component:
```
<FaGithub />
```
